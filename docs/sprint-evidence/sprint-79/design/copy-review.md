# 案例库 v2 UI 文案评审

评审基线：`prototype-v2.html`、`uiux-spec-v2.md`、现网 `index.html:2097-2394`
评审原则：
- **A（复杂度留给系统）**：界面不暴露系统内部概念（`case_type` / `PI` / `facet` / `分层可追溯` / `真实库` / `自动识别` 等）。
- **B（简练不话唠）**：能一词不两词，能删副标题就删，标签不与值重复，禁止操作说明式文案。

## 2. 话唠清单（仅列重复表达 / 系统术语 / 标签与值重复）

1. **`类型分布（真实库）`**（`prototype-v2.html:223`）：括号解释「真实库」属于研发自证口径，用户视角默认数据就是真的。
2. **`按企业聚合` / `按行业聚合` / `按业务场景聚合`**（`:229-231`）：连续三次重复「按……聚合」，全属系统查询术语。
3. **`企业 facet → 腾讯`**（`:319`）：直接把 `facet` 英文术语暴露给业务用户。
4. **`证据链（分层可追溯）`**（`:291`）：括号内是技术架构说明，对阅读无帮助。
5. **列表卡三连重复**（`:474-484`）：同一张卡里同时放 `cc-verdict`（标题）、`cc-sum`（摘要）、`cc-why`（为什么值得看），三段都在复述「小微日活 3000 万，30+ 场景」。
6. **详情页四连重复**（`:247, 254, 265, 293-294`）：标题、为什么值得看、一句话结论、证据里的摘要/参考依据，4 处均在讲同一件事（现网 `index.html:2316/2324`「案例摘要 + 参考价值依据」与新设计的「结论 + 看点」重叠）。
7. **标签与值重复**：`参考价值 · 高` / `参考价值 高` / `参考价值：high`（现网 `index.html:2158`、`prototype-v2.html:224,490`）——「高/中/低」徽章已经配了红/黄/灰颜色，改为 `高价值` / `中价值` / `低价值` 即可。
8. **`生成分享（卡片 / 长图 / 简报）`**（`:326`）：按钮里把子菜单项全部括号列出来。
9. **`形态 1 · 案例卡片（1:1 方图）` / `形态 2 · 长图（9:16 竖幅）` / `形态 3 · 简报（文档式）`**（`:340,354,370`）：把设计交付物的编号和画幅规格当成了 UI 文案。
10. **空状态解释后台机制**（`prototype-v2.html:458`、`uiux-spec-v2.md:60`）：大段解释「系统会从文章中自动识别……也可以打开单篇文章点……」；以及 `uiux-spec-v2.md:29` 的 `reference_rationale` 等字段名注意不要带进前端。

## 3. 必须保留（不可删除）

| 标签 / 元素 | 位置 | 保留理由 |
|---|---|---|
| **参考价值三档**（建议简写为 `高价值` / `中价值` / `低价值`） | 列表卡、详情页、筛选栏、统计卡 | 核心过滤漏斗。现网 `index.html:2128/2158` 已上线并用于区分值得抄的标杆（137 条）与普通动态（295 条），删掉后无法做优先级排序。 |
| **动作标签**（`上线` / `试点` / `规模化` / `转型` / `退出`） | 列表卡、详情基本信息 | 区分「真上线」与「小范围试点 / 退出」，直接决定同业借鉴成熟度。 |
| **关键数字（指标名 + 数值 + 单位）** | 列表卡、详情 Hero、分享卡片 | 例：`互动日活` `3000` `万 / 日`。缺指标名会退化成无意义的「3000 万元」，缺单位则口径失真。 |
| **风险与前提** | 详情页、简报 | 防误导必需项（如「厂商自述口径」「依赖存量入口」），没有它同业容易盲抄。 |
| **原文链接 & 原文引文** | 详情页底部 | 可信度锚点，方便读者点击核对原始出处。 |
| **案例编号 `MN-AI-2611-0004`**（仅详情页角标保留） | 详情页标题旁（弱化展示） | 汇报引用与工单检索的唯一锚点，但不应放在列表卡片首行。 |

## 4. 详情页小节标题最终 6 条（最小集合，直接可替换）

把原型里分散的 1 个顶部 box + 4 个主区 `.sec` + 3 个侧栏 `h5` 收敛为 **6 个不重叠小节**（主栏 4 + 侧栏 2，「分享」直接做成侧栏顶部主按钮组，不单占一个标题）：

### 主栏（4 节，回答「是什么、怎么抄、有什么坑、出处在哪」）
1. **`结论`**（合并原 `为什么值得看` + `一句话结论`：首句给事实结论，次句点明同业参考点）
2. **`关键数字`**（原 `hero-metrics` 块加标题，或直接数字大卡紧跟在 `结论` 下）
3. **`做法`**（替代 `可迁移做法`：2–3 条可落地动作）
4. **`风险与前提`**（保留原名）
5. **`原文证据`**（替代 `证据链（分层可追溯）`：只留 1–2 句原文引文 + 来源文章链接，删掉重复的 `摘要` 和 `参考依据` 行）

### 侧栏（2 节 + 1 组操作按钮）
6. **`基本信息`**（替代 `企业画像`：企业 / 行业 / 场景 / 类型 / 动作 / 时间）
7. **`相关案例`**（替代 `同类案例`：同企业或同场景案例，最多 3 条 +「查看全部」链接）
- 底部/顶部操作区直接放 `生成分享`、`复制链接` 按钮，不再多套一层 `分享` 小节标题。

*(注：若 `关键数字` 作为无标题视觉大卡展示，则主栏文字小节为 `结论`、`做法`、`风险与前提`、`原文证据` 共 4 条 + 侧栏 `基本信息`、`相关案例` 共 2 条 = **恰好 6 条小节标题**。)*
