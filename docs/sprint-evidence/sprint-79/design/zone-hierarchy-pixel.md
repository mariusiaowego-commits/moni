# 案例库三层区域 UI 区分方案

基线：`docs/sprint-evidence/sprint-79/design/prototype-v2.html:63-98`（token 与组件）。
说明：brief 引用的 `docs/plans/2026-11-26-cases-ui-round2.md` 与 `render/prototype-stats-1440.png` 在仓库中不存在（已核对），本方案以 prototype-v2 与 oklch token 为准。
范围：只出设计 + 静态 mock，不改仓库。

## 0. 问题定位

三层现在同用 `--card` 底 + 1px `--border` + 12px 圆角 + 相近内距（`.stat` 16/20、`.facet` 16、`.case-card` 20），所以「概览 / 控制 / 内容」在视觉上是一个东西。
可用的**非颜色**杠杆只有四个：表面明度、边框纹理、圆角、字号角色。灰度下唯一可靠的是明度与纹理。

token 实测（oklch→sRGB，相对亮度）：

| token | sRGB | 相对亮度 | 灰度可辨 |
|---|---|---|---|
| `--card` | 255 254 249 | 98.9 | 最亮 |
| `--background` | 245 243 233 | 89.4 | 中 |
| `--muted` | 242 230 206 | 79.9 | 较暗 |
| `--border` | 217 203 184 | 60.8 | 最暗（线） |

三层明度差 9.5 与 9.5，均为可辨级差（>5），这是方案 1 的地基。

## 方案 1（推荐）三档表面：无框 / 内凹 / 抬起

| | A 概览 KPI | B 筛选控制 | C 案例卡 |
|---|---|---|---|
| 表面底色 | 透明（`--background`） | `--muted` | `--card` |
| 边框 | 上下各 1px `--border`（hairline） | 1px `--border` 实线 | 1px `--border` 实线 |
| 圆角 | 0 | 6px（`--radius-sm`） | 12px（`--radius-lg`） |
| 阴影 | 无 | 无 | 仅 hover：`--shadow` |
| 内边距 | 16px 0 | 12px 16px | 20px（1024：16px） |
| 字号层级 | 数字 28/600/1.1 + 标签 13/400 | 胶囊 13/400（计数 12 mono） | 标题 16/600 + 正文 13/1.55 + 元 12 |
| 区域间距 | A→B 24px；B→C 24px | | |
| 分隔方式 | hairline 线 + 留白 | 底色差 + 边框 | 底色差 + 圆角 + hover 抬升 |
| hover | 无（只读） | 边框转 `--muted-fg` | `translateY(-1px)` + `--shadow` |
| active | 无 | 选中 `--foreground` 底 / `--background` 字 | `scale(.995)` |
| selected | 无 | 胶囊黑底 + 计数 | 无 |
| 不要做 | 不加卡片、不加阴影、不加 accent 底 | 不用 12px 圆角（会与 C 混）；不用虚线 | 不放大数字到 28px（抢 A 焦点）；不做渐变 |

**为什么推荐**：三层在灰度下是 98.9 / 79.9 / 89.4 三个明度 + 0 / 6 / 12 三个圆角 + 有线 / 无线两种边界，三重编码，不依赖色相；A 无框读作「页面级事实」，B 内凹读作「可操作」，C 抬起读作「可点对象」；不需要任何区域标题。

## 方案 2 边框纹理：无框 / 虚线 / 实线

| | A | B | C |
|---|---|---|---|
| 表面 | `--background` | `--card` | `--card` |
| 边框 | 仅上 1px 实线 `--border` | 1px **dashed** `--border` | 1px **solid** `--border` |
| 圆角 | 0 | 6px | 12px |
| 阴影 | 无 | 无 | hover `--shadow` |
| 内边距 | 16px 0 | 12px 16px | 20px |
| 字号 | 28/600 + 13 | 13 胶囊 | 16/600 + 13/1.55 |
| 交互 | 无 | hover 边框转 `--muted-fg`；选中黑底 | hover 抬升 |
| 不要做 | 不给 A 加底色（否则与 B 同明度） | 虚线只给 B，C 用虚线会像占位 | 三层都用阴影 |

灰度：实线 / 虚线 / 无线是**纹理**差异，与明度无关，灰度同样成立；但 B 与 C 同为 `--card` 底，明度不分层，靠纹理与圆角区分，弱于方案 1。

## 方案 3 排版角色：字号与密度

| | A | B | C |
|---|---|---|---|
| 表面 | 透明 | `--muted` | `--card` |
| 边框 | 无 | 1px `--border` | 1px `--border` |
| 圆角 | 0 | 6px | 12px |
| 字号 | 28/600 数字（唯一大字号） | 13 胶囊，禁 >13 | 16 标题 + 13 正文 + 12 元 |
| 行高 | 1.1 | 1.4 | 1.55 |
| 密度 | 4 列等距 | 单行横排 | 3 段纵向 |
| 不要做 | 不让 B 出现 16px 以上；不让 C 用 28px 数字 | | |

灰度：A 与 C 都是文字块，仅靠 28 vs 16 的字号差与 hairline 区分，**必须**配 A 的上下细线才成立；单独用不够。

## 推荐与理由

**推荐方案 1**，必要时把方案 2 的虚线只用在 B 的展开面板（强化「可展开」暗示）。
理由：
1. 明度三档（98.9 / 79.9 / 89.4）是 token 自带的，零新增色板，灰度天然分层。
2. 圆角 0 / 6 / 12 与「有线 / 无线」再编码一次，色盲与打印灰度都不丢。
3. A 无框 = 只读事实，B 内凹 = 控制面，C 抬起 = 内容对象，语义与视觉同向，不靠标题解释。
4. 不引入渐变、发光、玻璃、大阴影，符合约束。

## 1440 与 1024 的真实差异

| 项 | 1440×900 | 1024×768 |
|---|---|---|
| KPI 列数 | 4 列，gap 12px | 4 列，gap 8px（不换行、不滚动） |
| KPI 内距 | 16px 0 | 14px 0 |
| 筛选胶囊 | 单行，gap 8px | 单行横滚（不换行），gap 8px |
| 筛选内距 | 12px 16px | 10px 12px |
| 展开面板限高 | 240px | 200px |
| 案例卡列数 | 3 列（`minmax(340px,1fr)`） | 2 列（`minmax(300px,1fr)`） |
| 卡内距 | 20px | 16px |
| 区域间距 | 24px | 16px |
| 字号 | 28 / 16 / 13 / 12 | 不变 |

只有以上 8 项变，其余（颜色、圆角、边框、字重）两档一致。

| 前景 / 背景 | 对比度 | 判定 |
|---|---|---|
| `--card-fg` on `--card` | 17.21 | AAA |
| `--card-fg` on `--background` | 15.64 | AAA |
| `--card-fg` on `--muted` | 14.06 | AAA |
| `--muted-fg` on `--card` | 6.31 | AA |
| `--muted-fg` on `--background` | 5.73 | AA |
| `--muted-fg` on `--muted` | 5.15 | AA |
| `--accent-fg` on `--accent` | 9.60 | AAA |

灰度编码：A 明度 89.4 无框 + 上下细线（60.8）；B 79.9 内凹 + 6px 圆角 + 实线；C 98.9 抬起 + 12px 圆角 + hover 阴影。三层在 `filter:grayscale(1)` 下仍可辨（见 `zone-hierarchy-gray.png`）。

## 验收（实测）

- 横向溢出：1440 档 `scrollWidth/clientWidth = 1440/1440`；1024 档 `1009/1009`（1024 减 15px 滚动条），两档均无横向滚动。
- 截图：`/private/tmp/zone-hierarchy-1440.png`、`/private/tmp/zone-hierarchy-1024.png`、灰度 `/private/tmp/zone-hierarchy-gray.png`（`?gray=1`）。
- 数值落地：KPI 28/13、胶囊 30px/999、卡 12px 圆角、区间距 24/16、面板 240/200，均直接写为 CSS 变量或 px。

## 三行摘要

1. 推荐「三档表面」：A 无框（`--background` + 上下 hairline + 圆角 0）、B 内凹（`--muted` + 1px + 6px）、C 抬起（`--card` + 1px + 12px + hover `--shadow`）。
2. 灰度靠明度 98.9 / 79.9 / 89.4 + 圆角 0/6/12 + 有线/无线三重编码，不依赖色相，正文对比度 5.15–17.21 全过 AA。
3. 1440 与 1024 只差 8 项（KPI gap 12/8、卡 3/2 列、卡内距 20/16、区间距 24/16、面板 240/200 等），1024 不横向滚动。
