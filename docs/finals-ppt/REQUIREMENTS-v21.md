## 2. 截图与正文数字统一

- 冲突：v20 的 P03 截图里可见「共 6789 篇」（2026-11-26 16:54 生产实时数），正文固定口径 **6,727 篇**（申报材料口径）。
- 统一方式：**抹掉截图里的实时总数**，正文 6,727 不动。
  - 理由一：实时数每天涨，归档时生产库已到 9,209 篇，任何"改成实时数"的做法次日又不一致。
  - 理由二：申报材料口径是评委手上的固定基准，不能动。
- 素材：`.ppt-work/assets/p03-pick-clean.png` = `pick-v2.png` 抹掉「共 6789 篇」像素段（rect x 106–258, y 228–272，填充取同区域背景色 255,254,249），其余像素未改。
- 结果：全片只出现 6,727 这一个入库篇数；方向标签桶（银行 3571 / AI×金融 2813 / 微信生态 1461 …）保留，那是筛选维度不是总量。
