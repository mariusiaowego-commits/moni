## 3. 文风规则（必须遵守）

1. 眉标：P01/P02 只留页码 `01`/`02`；内容页保留 `03 环节一 · 内容处理` 格式。
2. 标题统一「标签：陈述」；标签与正文同字号同色（深蓝粗体）。
3. 页脚统一「新媒体渠道同业跟踪调研 AI 工作台」（去掉 `moni ·` 前缀）。
4. 卡片标签用名词短语（我们的职责 / 要盯什么 / 存在问题 / 知识库管理 / 团队辅助决策 / 案例库使用场景）。
5. 问题区用「粗体小标题 + 浅灰解释」两段式。
6. 左侧流程轨：眉标 `流程 · N/5`；分支页 `流程 · 3 分支 5/5` + 金色胶囊 `↓ 深度阅读 · 分支`。
7. 流程轨节点：内容处理 / 价值评估（`0–100，低分归档`）/ 事实核查（`结论带出处，逐条核对原文`）/ 提取案例 / 分享简报（`8 种格式，按场景分享`）。
