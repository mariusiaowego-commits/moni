## 0. 一句话：演练台是什么

**一个 URL 打开的实验台**：贴一段含敏感信息的文本 → 点「真跑一次」→ 屏幕上并排出现四栏：

| 栏 | 内容 | 现场要说的 |
|---|---|---|
| ① 原文 | 用户输入的真实文本（含手机号 / 机构名 / 身份证） | 「这是库里的一篇真文章」 |
| ② 发给模型的内容 | 遮蔽后的文本 + 一行系统脱敏说明 | 「模型**只**看得到编码」 |
| ③ 模型回包（原始） | 大模型返回的**未经还原**的原文，含 `{{PHONE_xxx}}` | 「模型回话里也只有编码」 |
| ④ 本地还原后 | moni 还原出来的明文 | 「用户最终看到的仍是明文，功能不受损」 |

下面一条指标带：**遮蔽 N 处 / 还原 N 处 / 未还原 0 / 出站泄漏命中 0 / 残留占位符 0 / 耗时 ms**。

## 1. 对决赛有什么用（为什么值得做）

1. **把「我说是安全的」变成「现场看见的」**。PPT 讲脱敏，评委心里默认是「厂商吹的」；
   现场四栏并排 + 数字实时跳出来，是唯一能压住这种质疑的形式。
2. **证明它不是纸面功能**。①②③④ 里的第③栏是**真实模型**的输出（不是预先录好的图），
   这一点必须现场说明，否则会被问「这图是不是做的」。
3. **指标是反直觉的强点**。「出站泄漏命中 = 0」「未还原 = 0」是 magpie 没有的
   （magpie 的 `maskrec.Summary()` 连还原成功率都没有字段，见 `internal/maskrec/summary.go:122`）。
   现场用一条 SQL 把账本复算出来，评委当场看到数字对得上。
4. **跟 moni 主线咬合**。moni 是「同业投研情报系统」，敏感信息不是泛泛的 PII，
   而是**投研判断本身**（目标清单、内部结论、作者身份）—— 这是 magpie 结构上做不到的一格。
5. **零风险**：演练台只是**读 + 一次显式模型调用**，不写业务数据；脱敏总开关保持关，
   生产行为与上线前逐字节一致（`docs/sprint-evidence/sprint-68/RUN.md` §7）。

## 2. 现场怎么演示（分镜脚本，建议 90–150 秒）

**准备（上场前 5 分钟）**
- 浏览器开两个标签：`http://127.0.0.1:8900/static/desens-lab.html`（演练台）、
  `http://127.0.0.1:8900/`（moni 主界面，证明它长在产品里）
- 演练台页面里预先放好示例文本（点「示例」按钮自动填入）
- 确认脱敏总开关是 **关**（默认状态），页面右上角有显示
- 准备一个兜底：提前截好一张四栏图（贴到 PPT 里当静态页），防网络/模型抖动

**分镜**

| 时刻 | 动作 | 台词（≈） |
|---|---|---|
| 0:00 | 切到演练台，指四栏标题 | 「这是 moni 发给大模型之前的一道闸。今天现场跑一次真实模型。」 |
| 0:10 | 点「真跑一次」（模型回包约 5–15 秒） | 「左边是原文，中间是模型**实际**收到和**实际**返回的内容。」 |
| 0:30 | 用鼠标依次划过 ②③ 两栏 | 「注意第③栏——模型回话里也是编码，它从头到尾没见过我们的手机号。」 |
| 0:50 | 指着第④栏和指标条 | 「第④栏是 moni 本地还原后的结果，用户该看到的还是明文，功能一点没坏。」 |
| 1:05 | 指着「出站泄漏命中 0 / 未还原 0」 | 「这两个零是可复算的：每次出站都对真正发出的内容做一次敏感串扫描，命中数必须恒为 0。」 |
| 1:20 | 切到 SQL 那一块（或 PPT 预截图） | 「账本在 `desensitize_events` 表，一条 SQL 就能把这次调用复算出来。」 |
| 1:40 | 收尾 | 「通用网关级脱敏只遮密钥账号，看不见业务语义；moni 遮的是**投研判断**，还多两项它算不出的指标。」 |

**可能被问到的问题 / 应答**
- 「模型会不会因为看到编码就答不出来？」→ 现场把示例文本换成含机构名的，答：占位符是**同值恒定同码**
  （`{{ORG_jcwwdnrn}}` 始终代表同一机构），且出站会注入一行说明让模型照抄编码；
  联网核查场景按策略**保留公开机构名**，只遮敏感项。
- 「还原错了怎么办？」→ 未知编码**原样保留不猜**，并计入「未还原」；写库前还有残留占位符扫描，
  不允许占位符污染 `articles.summary`。
- 「脱敏器挂了会不会让分析停摆？」→ 默认 **fail-open**：脱敏异常走零依赖擦除器放行，
  不因脱敏让任务失败（严格模式可开，对齐 magpie 的 fail-closed）。
- 「有没有参考同类方案？」→ 参考过通用网关级思路，代码未复用；
  插入层、检测语义、指标三处都不同，详见两版设计对比文档。

## 4. 关键口径（PPT 上的数字必须能复算）

| 指标 | 口径 | 复算 |
|---|---|---|
| 遮蔽处数 | `sum(masked_total)` | `SELECT sum(masked_total) FROM desensitize_events;` |
| 精确还原成功率 | `sum(restored_total) / (sum(restored_total) + sum(unrestored_count))` | 同表聚合 |
| 出站泄漏命中 | `sum(leak_scan_hits)`，**期望恒为 0** | 同表聚合 |
| 残留占位符 | `sum(residual_placeholders)`，**期望恒为 0** | 同表聚合 |
| 去重敏感实体数 | `COUNT(DISTINCT placeholder)`（**不能**把每行 `masked_distinct` 相加） | 从 `items_json` 展开 |

> 生产口径**排除**演练台自己的调用（`call_site = 'desens_lab'`）——演练台的数字单列。

## 6. 兜底（万一现场出事）

| 风险 | 应对 |
|---|---|
| 网络/模型慢 | 提前录一份四栏 GIF/截图放 PPT；现场最多等 30 秒，超时切静态页 |
| 模型不复述编码 | 换个示例文本（含「请原样复述」指令）；这一栏本来就允许模型自由发挥，不影响结论 |
| 演练台页面打不开 | 提前把页面截图贴 PPT；同时保证 moni 主界面能打开，证明功能在产品里 |
| 评委追问「网关层也能做」 | 答插入层与检测语义差异 + 它算不出的两项指标 |
