# 菜篮子 (Basket) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 被 tag 过滤丢弃的文章存入"菜篮子"表，用户可在 UI 查看、编辑 tag、 rescue 回正式文章库。

**Architecture:**
- 新增 `basket` 表（schema 同 articles，加 `dropped_reason` / `dropped_by` 字段）
- 修改 `apply_keyword_filters()` 和 `apply_tag_keyword_filter()` —— 丢弃时同时写 basket
- 新增 `/api/basket` CRUD 端点
- 新增「菜篮子」UI tab（表格 + 详情弹窗 + tag 编辑 + rescue 流程）

**Tech Stack:** Python / SQLite / FastAPI / Alpine.js

---

## 当前过滤流程（base.py:207-247）

```
parsed_articles
  → apply_keyword_filters()     # 黑名单/白名单过滤
  → apply_tag_keyword_filter()  # tag 关键词过滤
  → filtered_articles
  → dedupe_insert()             # 写入 articles 表
```

被丢弃的文章目前直接丢失，没有存储。

## 数据安全评估

- **无毁灭性影响**: basket 是新表，不影响现有 articles 表
- **过滤逻辑不变**: 只在丢弃时多写一笔到 basket，不影响 kept 文章的入库流程
- **rescue 操作**: INSERT INTO articles + INSERT INTO article_tags，不修改现有数据

```sql
-- 014_basket.sql
-- 菜篮子: 被过滤丢弃的文章暂存区

CREATE TABLE IF NOT EXISTS basket (
    id                      TEXT PRIMARY KEY,
    title                   TEXT NOT NULL,
    url                     TEXT NOT NULL,
    source                  TEXT NOT NULL,
    publisher               TEXT,
    published_at            TEXT,
    fetched_at              TEXT NOT NULL,
    raw_content             TEXT,
    dropped_reason          TEXT NOT NULL,      -- 'blacklist' | 'whitelist' | 'tag_filter'
    dropped_by              TEXT,               -- 命中的关键词或 tag 名
    rescued_at              TEXT,               -- 被 rescue 到 articles 后标记时间
    created_at              TEXT NOT NULL,
    UNIQUE(source, url)
);
CREATE INDEX IF NOT EXISTS idx_basket_source ON basket(source);
CREATE INDEX IF NOT EXISTS idx_basket_created ON basket(created_at);
CREATE INDEX IF NOT EXISTS idx_basket_rescued ON basket(rescued_at);
```

**Step 1: 在 filters.py 中添加写 basket 的辅助函数**

```python
def _insert_basket(art: dict, reason: str, dropped_by: str) -> None:
    """将被过滤丢弃的文章写入 basket 表."""
    from moni.db.connection import get_db
    from datetime import datetime, timezone
    conn = get_db()
    now = datetime.now(timezone.utc).isoformat()
    art_id = art.get("id") or _make_article_id(art.get("source", ""), art.get("url", ""), art.get("title", ""))
    try:
        conn.execute(
            """INSERT OR IGNORE INTO basket
               (id, title, url, source, publisher, published_at, fetched_at,
                raw_content, dropped_reason, dropped_by, created_at)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)""",
            (art_id, art.get("title", ""), art.get("url", ""),
             art.get("source", ""), art.get("publisher"), art.get("published_at"),
             art.get("fetched_at", now), art.get("content") or art.get("raw_content"),
             reason, dropped_by, now),
        )
        conn.commit()
    except Exception:
        logger.debug("[basket] failed to insert %s", art.get("url", "")[:60])
```

## Task 3: Basket API 端点

**Objective:** 提供 basket 列表/详情/rescue CRUD 接口

**Files:**
- Create: `moni/web/routes/basket.py`
- Modify: `moni/web/server.py` (注册路由)

**端点设计:**

| Method | Path | 说明 |
|--------|------|------|
| GET | `/api/basket` | 列表（分页 + source/tag 筛选） |
| GET | `/api/basket/{id}` | 详情 |
| POST | `/api/basket/{id}/rescue` | rescue 到 articles（附带 tag 选择） |
| DELETE | `/api/basket/{id}` | 从 basket 删除（不要的直接清掉） |

**rescue 流程:**
1. 读 basket 记录
2. INSERT INTO articles（用 basket 的字段）
3. INSERT INTO article_tags（用户选择的 tag，predicted=0）
4. UPDATE basket SET rescued_at = now
5. 返回成功
