## Goal (一句话)

用户 pin 了 N 篇文章后，**只选一次格式 + 点一次按钮**，即可生成含摘要 / 事实核查 / 评分 / 业务价值评判的简报，并随时看到生成状态。

## 现状痛点（实测分享页）

当前分享路径约 **8–12 次操作**：

| # | 步骤 | 问题 |
|---|------|------|
| 1 | 进分享页 → 切「仅 Pin」 | 默认已是 Pin，但卡片仍需**逐个勾选** |
| 2 | 分页 / 筛选 | Pin 跨页时勾不全 |
| 3 | 选格式 | 必要 |
| 4 | 标题 / 内容选项 / BB 增强 / 高级 / 生图 | **认知负担重**，多数次次重勾 |
| 5 | 「加入队列」→ estimate 确认 modal | 多一跳 |
| 6 | 「▶ 立即处理队列」 | **二次按钮**，易漏 |
| 7 | 看队列表 + 可选 worker log modal | 状态有，但 enrichment 阶段粗 |

**已有但未串成一键的能力**：`include_abstract` / `include_fact_check`、BB 增强、`progress_stage` 五档、Pin 数据源、`POST /api/share/worker/run`。

**缺口**：无「业务价值评判」字段；无「用全部 Pin 一键生成」；create 后不 auto-launch worker；无 opinionated brief 预设。

## 验收 (TDD + 手动)

### 自动测试
- [ ] `POST /api/share/brief`：空 pin → 400；有 pin + format → 201 + `share_id` + auto-pending
- [ ] create brief 后 worker 被 launch（或已有 running 则 queue）
- [ ] payload 默认：`include_abstract=true`, `include_fact_check=true`, 业务价值 on
- [ ] progress 阶段含 enrichment 细分（至少 summary / fact_check / business_value / render）
- [ ] 业务价值字段写入 articles（或 task 级 JSON）可查询
- [ ] 全套 pytest 不回归（428+）

### 手动 (UI)
- [ ] 分享页顶部主 CTA：「用当前 Pin 生成简报」(N 篇)
- [ ] 仅需选 format（+ 可选标题）；高级选项折叠默认关
- [ ] 一点即进队列且开始处理，**无需**再点「立即处理」
- [ ] 队列/状态区实时 progress（可离开页面再回来继续看）
- [ ] 完成后可打开 artifact；失败有可读 error

### 回归
- [ ] 旧路径「勾选文章 → 加入队列 → 处理」仍可用（power user）
- [ ] Pin / 抓取 / fetch modal 不破

## 非目标 (本版本不做)
- 每日定时自动简报（cron 日报）→ 可放 v1.0.11
- 队列迁 SQLite / worker Python 化（审计 P2 稳定性根治）
- 新分享格式
- 移动端专项

## 风险
| 风险 | 缓解 |
|------|------|
| 10 篇 × 摘要+事实核查+业务价值 → 超时 | 逐篇缓存到 articles；worker timeout 已 600s；分阶段 progress |
| hermes 失败整单挂 | 单篇 enrichment 失败记 note，不阻断整 brief（可配置） |
| BB API 额度 | brief 默认 **不**强依赖 BB；BB 增强仍 opt-in 高级 |

## 决策锁定（三方评审后，2026-07-28）

| # | 决策 | 锁定值 |
|---|------|--------|
| D1 | 默认 format | **markdown** |
| D2 | 业务价值 persona | **固定**银行/支付/数字化同业（不可配 v1） |
| D3 | 生成后 pin | **保留** |
| D4 | 一键范围 | **全部 pin**（不读勾选；子集走自定义） |
| D5 | 单篇 enrich 失败 | **继续** + 产物标注 |
| D6 | confirm | **零 modal**；一行非阻断预估文案 |
| D7 | 排序 | **business_value_score desc**，同分 pin 序 |
| D8 | 标题 | 自动 `同业简报 YYYY-MM-DD`（html/pdf 也不阻断） |
| D9 | 旧 API auto_start | **v1 不加**；仅 brief endpoint auto-launch |
| D10 | 2 天 MVP 砍线 | summary + business_value 落库；fact_check 尽量落库；quality 可复用 bb_score，可不新列 |

### 必须进实现的 P0（共识）
1. **产物模板**必须露出摘要/核查/评分/业务价值（改 prompt，不只写 DB）
2. **formats.py** 加 `include_business_value` 等字段（`extra=forbid`）
3. **enrich 后 re-read** 再拼 format prompt（否则字段进不了产物）
4. **超时**：按缺字段篇数估时；整 task enrich 预算；非单靠 600s format timeout
5. **fact_check 真落库**（现状 worker 只写进 prompt）
6. **UI**：唯一主 CTA；自定义折叠；sticky 当前任务卡片；中文阶段；失败可重试
7. **stage pct 单调**；BB off 时不出现 bb stage

### 实现顺序（修订）
1. formats + migration + version bump  
2. enrichment.py（mock hermes 单测）  
3. POST /api/share/brief + auto launch  
4. worker hook + re-read  
5. prompt 模板（markdown brief 结构 + 排序）  
6. UI 主路径 + 状态卡片  
7. 测 + STATUS/USER_GUIDE + PR
