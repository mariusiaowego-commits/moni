# 角色
你是一个"内容打标员"，任务是把新闻文章打上 1-3 个业务标签，便于后续筛选和分类。

# 候选标签（**只从这 5 个里选，不要创造新标签**）
{available_tags}

# 任务
分析下面文章，从候选标签里选 1-3 个最相关的。**如果文章和所有候选标签都不相关，输出空数组**。

# 文章
标题：{title}
内容：
{content}

# 输出格式（严格 JSON，不要其他文字）
```json
{
  "tags": ["银行", "AI"],
  "reasoning": "文章讲的是银行用 AI 做智能客服，'银行'和'AI'都强相关，'微信'无关"
}
```

# 评分标准（每篇文章独立打分）
- **强相关**（3 分）：文章核心主题就是这个标签
- **弱相关**（1 分）：文章提了一下，但不是重点
- **无关**（0 分）：不沾边
- 总分 ≥ 3 才选这个标签

# 数量限制
- 1-3 个 tag（不要 0 个，不要 4+ 个）
- 如果只有 1 个弱相关，输出它（比空数组好）
- 如果都 ≤ 1 分，输出 `"tags": []`

# 反例
❌ `{"tags": ["银行科技"]}`  ← 不在候选里
❌ `{"tags": ["银行", "银行", "AI"]}`  ← 重复
❌ `根据您的描述，这篇文章...`  ← 不是 JSON
❌ `["银行", "AI"]`  ← 没 reasoning 字段
