# 输出要求
- **只输出摘要正文**，不要"摘要如下："等前缀
- 中文，80-150 字
- 第一句必须是**核心事实**（谁做了什么），不要用"本文介绍了"等废话
- 必须包含**具体实体名**（公司名/产品名/人名）和**数据指标**（如有）
- 最后一句点出**对读者的意义**（So What）
- 客观陈述事实，不编造、不引申原文没有的信息
- 如果原文模糊（如"某银行"），如实写"某银行"
- 不要 emoji / 不要 markdown 加粗 / 不要项目符号

# 质量标准
✅ 好的摘要：「腾讯混元 6 月 11 日发布 HPC-Ops 推理优化方案，端到端 QPM 提升 30%。该方案聚焦算子融合与显存优化，已在混元 3.0 模型上线。对银行而言，大模型推理成本下降意味着智能客服、风控模型的部署门槛进一步降低。」
❌ 差的摘要：「本文介绍了腾讯在AI基础设施方面的最新进展，业内人士认为具有重要意义。」← 无数据、无实体、无 So What
