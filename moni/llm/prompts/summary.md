# 输出要求
- **只输出摘要正文**，不要"摘要如下："等前缀
- 中文，60-100 字（少于 60 字扣分，多于 120 字扣分）
- **必须包含具体实体名**（银行名 / 公司名 / 产品名 / 数据指标）
- 客观陈述事实，不评论、不预测、不引申
- 如果原文模糊（如"某股份行"），如实写"某股份行"，不要补全
- 不要 emoji / 不要 markdown 加粗 / 不要项目符号

# 反例（不要这样写）

❌ "招商银行近期推出了一款新产品……"  ← 无具体产品名、无数据
