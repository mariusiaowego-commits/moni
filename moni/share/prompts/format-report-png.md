## Output format: Single PNG report image

Generate a single PNG image that summarizes all selected articles.
This is a one-image visual report for sharing on social media / chat.

### Generation method
Use the `image_generate` tool to create the image. Build a detailed
image generation prompt describing the full visual layout, then call
`image_generate` once to produce the final PNG.

If image generation fails (e.g. FAL backend unavailable due to Nous
subscription issues), report the error clearly: "Image generation failed.
Your Nous subscription may be disconnected. Please reconnect and retry."

### Image specs
- Orientation: portrait (vertical stack), suitable for phone screen sharing
- Background: clean and editorial — warm white or muted cream, no neon gradients
- Color palette:
  - Navy `#1a365d` — titles, key headings
  - Warm white `#fefdfb` — background
  - Muted gray `#64748b` — secondary text, dates
  - Amber `#f59e0b` — sparingly, for verdict markers or accent dots only
- Font style: serif for titles (editorial authority), sans-serif for body text
- No emoji decoration, no dashboard aesthetic, no heavy shadows

### Content layout (top to bottom, compact)

1. **Header section**
   - "行业追踪 · YYYY-MM-DD" in serif, navy
   - "from moni · N articles" in small, muted

2. **Article sections** (repeat per article, compact card style)
   - Article title: serif, navy, prominent but concise
   - Source + date: one line, muted, small
   - Key insight: 2-3 sentences capturing the most important takeaway
     (not the full abstract — pick the one thing the reader should remember)
   - Fact check (only if results exist): colored marker + ONE plain sentence,
     ≤60 Chinese characters, saying whether the article's core claim holds up
     and what that means for the reader.
     - Green ● = Supported
     - Amber ● = Unverified
     - Red ● = Disputed
     Override content-structure §3 for this one-image format: no per-claim
     detail. Hard rules:
     - Never copy numbers, ranges, parameter names, file names, URLs, domains
       or quoted text from the fact-check material.
     - No lists of 3+ items, no semicolons, no colon-then-list.
     - Write the meaning, not the comparison you ran.
     - Bad: 「温度 [0,2]、top_p [0,1]、频率惩罚 [-2,2] 均与官方文档一致」
     - Good: 「这套配置建议有官方文档支撑，落到实际调参仍取决于作者经验」

3. **Footer**
   - Thin separator line
   - "Generated by moni" in small, muted, centered

### Design rules
- Content-first: the image IS the report, not a teaser. Pack information
  densely but keep it readable.
- If 3+ articles: vertical stack layout, compact cards with thin dividers.
- If 1-2 articles: more spacious, larger titles, room to breathe.
- Text must be legible at 1x zoom on a phone screen — don't use tiny fonts.
- No fake data, no placeholder text — use the actual article content.
- Chinese articles: output Chinese text in the image.
- English articles: output English text in the image.

### Output
Save the generated PNG to the specified output path. Report the path
when done so the worker can register the artifact.
