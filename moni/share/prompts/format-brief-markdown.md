## Output format: 同业简报 Markdown（brief 模式）

你在生成 moni **一键简报**。输入文章已按业务价值分从高到低排好，并带有摘要 / 事实核查 / 业务价值字段。

### 强制结构

```
# 同业简报 — YYYY-MM-DD
*from moni · N 篇文章 · 按业务价值排序*

## 优先关注
1. **[标题]**（业务价值 XX）— 一句话：对己方意味着什么
2. ...
（取业务价值最高的 3–5 条；不足 3 条则全列）

---

## 1. [Article Title]

**来源**: … · **日期**: …
**质量/注意力分**: XX/100   （有 BestBlogs 分用 BB；否则质量分；都没有写「—」）
**业务价值**: XX/100 — note 原文

**摘要**:
> …

**事实核查**:
- …（无则写「无需核查」或「本篇 enrichment 未完成」）

[阅读原文 →](url)

---

## 2. …
```

### 规则
1. **必须有「优先关注」rollup**，不得只有逐篇列表。
2. **逐篇顺序**与输入一致（已按业务价值降序）。
3. 不得编造输入中没有的数字、监管结论、产品参数。
4. 业务价值 note 原样或轻度润色，禁止改成空话「值得关注」。
5. 薄文/失败篇：保留标题，标明「素材不足」或「本篇 enrichment 部分失败」。
6. 中文输出；无 emoji 装饰；`---` 分隔文章。
7. 文末一行：`*Generated by moni one-click brief*`
