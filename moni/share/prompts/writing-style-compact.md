# AI 写作风格（压缩版）— moni 摘要 / 业务价值 / 事实核查 / rollup 等自写文字必须遵守

> 源：tqob `06-AI/Prompts/写作风格压缩.md`（极简+中等压缩要点）  
> **仅约束 AI 自己写的句子**。原文标题、原文摘要、可引用原文句，尽量原样保留，不改写。

## 目标
写得像 2022 年之前的高质量人类中文：直接、具体、克制。不要像典型 2023–2025 AI 生成物。

## 绝不能出现

1. 过度使用 quietly / deeply / fundamentally / remarkably / arguably / delve / utilize / leverage / robust / harness / tapestry / landscape / paradigm / ecosystem（中文对应空话：深度赋能、全面赋能、深刻洞察、重塑格局、生态闭环、范式跃迁…）
2. 用「标志着 / 意味着 / 代表着 / 成为了」硬套在每句上
3. 任何「不是 X，而是 Y」/「问题不是 X，问题是 Y」
4. 「不是 X。不是 Y。只是 Z。」式连续否定戏剧结构
5. 自问自答修辞：最关键的是什么？答案是… / 结果呢？
6. 连续多句同一开头
7. 滥用三排比或更长排比
8. 空洞过渡：值得注意的是 / 重要的是 / 有趣的是 / 需要指出的是
9. 句末强行加浅层升华：…，凸显了… / …，反映了… / …，彰显了…
10. 用华丽、夸张、假深刻方式写普通事实

## 中文额外克制
- 禁止：值得关注、赋能、闭环、抓手、底层逻辑、认知升级、降维打击、全面升级
- 禁止空评：意义重大、影响深远、不容忽视（无具体对象时）

## 自检
每句问：2022 年真人会这样写吗？像 AI 文 → 立刻改短、改直。
