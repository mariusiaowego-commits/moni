## Output format: Single-file HTML

Render the analyzed articles as a single self-contained HTML page.
Focus: clean editorial reading experience, NOT a dashboard.

### Visual tokens (CSS variables)
| Token     | Value      | Usage                    |
|-----------|------------|--------------------------|
| --primary | `#1a365d`  | headings, links, buttons |
| --surface | `#fefdfb`  | page background          |
| --card    | `#ffffff`  | card background          |
| --border  | `#e2e8f0`  | card border, dividers    |
| --text    | `#1e293b`  | body text                |
| --muted   | `#64748b`  | meta, dates, secondary   |
| --accent  | `#f59e0b`  | tags, verdict markers    |

### Typography
- Headings: `Georgia, 'Noto Serif SC', 'Songti SC', serif`
- Body: `'PingFang SC', 'Hiragino Sans GB', system-ui, sans-serif`

### Spacing
- Card padding: 28px
- Card radius: 12px
- Card gap: 28px
- Container max-width: 720px, centered

### Forbidden
- Dark mode toggle, neon gradients, saturated backgrounds
- Glassmorphism, heavy shadows (cards: 1px border only, no shadow)
- Dashboard aesthetic, data panels, chart-like layouts
- Emoji as decoration
- Serif for body text

### Page structure

```
┌──────────────────────────────────────┐
│  HEADER                              │
│  Title: 行业追踪报告                 │
│  Subtitle: YYYY-MM-DD · N articles  │
│  "from moni" in italic, muted        │
│  ─── thin border-bottom ───         │
├──────────────────────────────────────┤
│  ARTICLE CARD (repeat per article)   │
│  ┌──────────────────────────────────┐│
│  │ [tag1] [tag2]          (badges) ││
│  │                                 ││
│  │ Article Title (serif, #1a365d) ││
│  │ Source · Date       (muted)    ││
│  │                                 ││
│  │ Abstract text here.            ││
│  │ (AI 生成) badge inline        ││
│  │                                 ││
│  │ ── thin divider ──            ││
│  │                                 ││
│  │ Fact Check                      ││
│  │ ● Supported — claim — reason   ││
│  │ ● Unverified — claim — reason  ││
│  │ ● Disputed — claim — reason    ││
│  │                                 ││
│  │ [阅读原文 →]  (outline button) ││
│  └──────────────────────────────────┘│
├──────────────────────────────────────┤
│  FOOTER                              │
│  Generated by moni · report id: xxx  │
│  (centered, muted, small)            │
└──────────────────────────────────────┘
```

### Card content (each article)
1. **Tag badges**: `<span>` with accent bg at 10% opacity, rounded, small font
2. **Title**: `<h2>` in serif, navy, links to original URL
3. **Meta line**: `<p>` muted, format: "Source · YYYY-MM-DD"
4. **Abstract**: `<p>` body text. If ai-generated, append a tiny `(AI 生成)` badge.
5. **Fact check** (omit section entirely if no checks): each claim as `<div>`:
   - Green `●` for Supported
   - Amber `●` for Unverified
   - Red `●` for Disputed
   - Claim text in quotes, then `—` then reasoning
6. **Read original button**: `<a>` styled as outline button, navy border

### Technical requirements
- Single `.html` file, CSS in `<style>`, no JavaScript frameworks.
- No Google Fonts CDN (system fonts only).
- Responsive: single column below 600px.
- CSS variables for all tokens.
- Cards: white bg + 1px solid var(--border) + 12px radius, **no shadow**.

## BestBlogs 增强数据（可选）

如果文章数据中包含 BestBlogs 字段（评分、摘要、要点、金句、BestBlogs 标签），按以下规则嵌入：

- **评分**：在标题后显示 `⭐ {score}/100`
- **摘要来源**：
  - 如果用户选了 "moni AI"：使用 AI 摘要，不展示 BestBlogs 摘要
  - 如果用户选了 "BestBlogs"：使用 BestBlogs 摘要，不展示 AI 摘要
  - 如果用户选了 "两者"：都展示，分别标注来源
- **要点**：渲染为编号列表，放在摘要之后
- **金句**：渲染为引用块（blockquote），放在要点之后
- **BestBlogs 标签**：追加到 moni tags 后面，用 `[BB: tag]` 格式区分
